## FAQ

### What is XCutors?

XCutors is a curated collection package that bundles several popular Roblox script executor tools — Volt, Synapse Z, Potassium, Wave — along with a universal loader called xcutorsLoader, all in one convenient download for Windows.

### Which Windows versions are supported?

XCutors supports Windows 10 (version 1903 and later) and Windows 11. Both 64-bit and 32-bit architectures are supported, though 64-bit is recommended for best performance.

### Do I need to disable my anticomponent?

Some anticomponent software may flag executor components as potentially unwanted programs due to their memory interaction behavior. You may need to add the XCutors folder to your anticomponent exclusion list. Always download only from the official GitHub Releases page to ensure file integrity.

### How do I switch between different executors?

Open xcutorsLoader and use the executor selector panel on the main dashboard. Simply click on the executor you want to use and press 'Initialize.' The loader handles environment setup for each engine automatically.

### Where can I find scripts to use?

XCutors includes a built-in script hub with community-sourced scripts organized by game and category. You can also load any local .lua or .txt script file, or paste a script URL to fetch and execute remote scripts.

### Do I get updates automatically?

The loader checks for executor updates each time it starts. If a new version is available for your selected executor, you will be prompted to download and apply the update with a single click.

### Can I run multiple executors at the same time?

No, only one executor engine should be active at a time per Roblox instance. Running multiple simultaneously may cause conflicts. The loader enforces this by requiring you to deactivate the current executor before switching.

### Is XCutors free to use?

XCutors itself is a free loader and collection tool. However, some bundled executors may require their own license or subscription. Check each executor's documentation within the package for individual licensing details.

### How do I report bugs or request features?

Open an issue on the GitHub repository with the appropriate label (bug or enhancement). Please include your Windows version, the executor being used, and steps to reproduce the problem so the team can investigate promptly.
